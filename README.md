# Fair Catch

מחשבון טריידים לפנטזי פוטבול. האתר: https://amit20b.github.io/fair-catch/

האתר נמצא בתיקייה `site`. הנתונים מתרעננים לבד כל שעה, וכל חצי שעה בימי ראשון ושני,
דרך הקובץ `.github/workflows/refresh.yml`. הרענון רץ על השרתים של גיטהאב, גם כשהמחשב כבוי.

## מה מתרענן לבד
- סטטיסטיקות שבועיות, לוח משחקים, יחסי הימורים ופציעות (nflverse)
- דירוגי מומחים וערכי טרייד (DynastyProcess, FantasyCalc)
- הסגלים, המאזנים והמעברים בליגת סליפר

## מה לא מתרענן כאן (עדיין)
- ליגת יאהו: צריך התחברות, אז היא נשארת כמו בעדכון האחרון
- התראות על הצעות טרייד
- המלצות המומחים השבועיות לקנייה ומכירה

## רענון ידני
**Actions** ← **Refresh and publish** ← **Run workflow**.

## אם משהו נכשל
גיטהאב שולח מייל כשריצה נכשלת. בריצה שנכשלה האתר לא משתנה, כי בדיקת הבטיחות עוצרת לפני הפרסום.
